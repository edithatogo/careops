## MoSCoW requirements

| ID | Priority | Requirement |
|---|---|---|
| 11_multilayer_networks-M1 | Must | Preserve provider, snapshot, field/grain, original attribution evidence, missingness, rights and effective dates. |
| 11_multilayer_networks-M2 | Must | Build and validate bibliographic coupling, co-citation, institution/author communities and temporal identity evolution. |
| 11_multilayer_networks-M3 | Must | Separate source Included, source candidate, independently human verified and rejected; no automatic approval. |
| 11_multilayer_networks-M4 | Must | Reproducible code, fixtures, adversarial edge cases, quantitative validation and exact-head CI. |
| 11_multilayer_networks-S1 | Should | Sensitivity analyses, uncertainty intervals and independent source method comparisons. |
| 11_multilayer_networks-C1 | Could | CiteLattice and Power BI versioned outputs if consumer contracts pass. |
| 11_multilayer_networks-W1 | Won't | Unfounded FWCI, disruption, clinical effect, institutional employment or causal impact claims. |

Full completion needs independently reviewed scientific evidence; implementation of a partial source algorithm is insufficient.
