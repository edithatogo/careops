# Scientometric methods and external validation — executable contract

**Goal:** Create independent affiliation gold standard, cross-source concordance and novelty/disruption bias benchmarks.

## MoSCoW requirements

| ID | Priority | Requirement |
|---|---|---|
| 15_reproducibility-M1 | Must | Preserve provider, snapshot, field/grain, original attribution evidence, missingness, rights and effective dates. |
| 15_reproducibility-M2 | Must | Create independent affiliation gold standard, cross-source concordance and novelty/disruption bias benchmarks. |
| 15_reproducibility-M3 | Must | Separate source Included, source candidate, independently human verified and rejected; no automatic approval. |
| 15_reproducibility-M4 | Must | Reproducible code, fixtures, adversarial edge cases, quantitative validation and exact-head CI. |
| 15_reproducibility-S1 | Should | Sensitivity analyses, uncertainty intervals and independent source method comparisons. |
| 15_reproducibility-C1 | Could | CiteLattice and Power BI versioned outputs if consumer contracts pass. |
| 15_reproducibility-W1 | Won't | Unfounded FWCI, disruption, clinical effect, institutional employment or causal impact claims. |

Full completion needs independently reviewed scientific evidence; implementation of a partial source algorithm is insufficient.
