# Specification — Evaluation, automation, security and scientific verification

## Goal
Reproduce the historical accepted cohort comparison without forcing equality; stratified adjudication audit; compare sources, cite network completeness and 23 historical measures without conflating populations.

## Requirements

**Must:** Single-developer CI: formatting, strict typing, unit/property/metamorphic/mutation tests, integration fixtures, licence and secret scans, dependency/SBOM, profiling, schema-drift gates; cadence with deterministic replays and documented access needs.

**Should:** retain replayable provenance, preserve data rights, integrate with existing RIMS contracts where equivalent and document divergences.

**Could:** add additional provider-supported metrics only if independently evaluated and source licensing permits.

**Won't:** assert live collection, RIMS native deployment, private employment affiliation or unverified CHHHS attribution.

## Acceptance criteria
Acceptance report includes precision/recall estimate or bounds, sample method, error taxonomy, cost/rate limit, release version, source attribution, unresolved cases and actual hosted CI evidence; no unqualified clinical-impact ranking.

## Evidence
No implementation or hosted test evidence recorded at creation. Record exact tests, commits, source snapshots and reviewer decisions in a subsequent evidence file.
