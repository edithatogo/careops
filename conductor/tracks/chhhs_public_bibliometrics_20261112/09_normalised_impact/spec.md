# Field-normalised citation influence — executable contract

**Goal:** Compute source-qualified field-year-type citation comparisons and top deciles from validated reference populations.

## MoSCoW requirements

| ID | Priority | Requirement |
|---|---|---|
| 09_normalised_impact-M1 | Must | Preserve provider, snapshot, field/grain, original attribution evidence, missingness, rights and effective dates. |
| 09_normalised_impact-M2 | Must | Compute source-qualified field-year-type citation comparisons and top deciles from validated reference populations. |
| 09_normalised_impact-M3 | Must | Separate source Included, source candidate, independently human verified and rejected; no automatic approval. |
| 09_normalised_impact-M4 | Must | Reproducible code, fixtures, adversarial edge cases, quantitative validation and exact-head CI. |
| 09_normalised_impact-S1 | Should | Sensitivity analyses, uncertainty intervals and independent source method comparisons. |
| 09_normalised_impact-C1 | Could | CiteLattice and Power BI versioned outputs if consumer contracts pass. |
| 09_normalised_impact-W1 | Won't | Unfounded FWCI, disruption, clinical effect, institutional employment or causal impact claims. |

Full completion needs independently reviewed scientific evidence; implementation of a partial source algorithm is insufficient.
