# Specification

Implement a non-premium default with every module/submodule optional. Preserve
premium work as explicitly selected extensions. Clinical Hub belongs logically
to Decisions while remaining standalone. PPG owns policy management; standards
and accreditation are optional. Improvement, RIMS and the dataset catalogue link
through references. Catalogue includes clinical registries and all CareOps
datasets without becoming their operational database.

Deliver an offline SharePoint setup package from existing schemas, an explicit
CLI ownership map, a read-only archive/recovery contract and an executable source
migration queue. Add privacy enforcement where CI omits it. Reconcile active
docs/profiles/Conductor and review the PR queue for protected merge.

Acceptance: fictional source tests and supported schema validation; optional
provider absence and premium exclusion; no weakened source/security gates;
source/inventory alignment; preserved native holds, record ownership and historical
evidence. Native commissioning, external source migration and host enrollment
require their listed tasks and cannot be inferred from this source increment.
