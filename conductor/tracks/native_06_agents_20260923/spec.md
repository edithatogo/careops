# N06 specification

Add bounded Copilot Studio/approved AI assistance only when it removes work.
Extraction, evidence comparison and drafting return sourced preparation findings;
no competence, scope, authority, approval or adverse decision is delegated to AI.

Owner: AI assurance owner. This optional track is not required for an AI-off
production release. Its own risk, privacy, cost and evaluation gates must pass
before agents are enabled. Acceptance includes all plan.md tasks and a tested
normal-human fallback, not merely good-looking example outputs.
