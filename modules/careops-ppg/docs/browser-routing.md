# Browser routing

The Codex internal browser is required unless the user explicitly states
otherwise, including sign-in, reauthentication, opening/loading pages, web
interactions and browser QA. Generic CLI-first preferences do not create an
exception. Local builds, tests and file work are separate. Follow task-specific
CLI/API instructions only for the operations they explicitly cover.

Report a specific internal-browser limitation instead of substituting another
browser. Never bypass authentication or safeguards, change credentials or grant
access under this rule. See [persistent module instructions](../AGENTS.md).

This module has no repository-owned SKILL.md. Host skills remain subordinate to
the user direction recorded in AGENTS.md; no shared skill was changed.
