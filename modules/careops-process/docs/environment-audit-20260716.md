# Environment capability and source boundary

The original dated environment audit is retained in private recovery history.
Personal identities, deployment names and tenant-specific capability observations
are not portable source configuration or current operational acceptance.

The supported preflight uses the existing approved user-scoped PAC/CLI and
Dataverse Web API route. It verifies source-read access separately from the
checkpoint/event destination, detects unavailable endpoints and customization
locks, and keeps evidence outside tracked source. No administrator privilege,
new client, permission change or broader source partition is inferred.

The reusable schema includes minimized checkpoint, event and dead-letter fields.
Use the existing metadata/exporter tests and privacy gates with fictional inputs.
A source/package check does not prove native publication, user-role access,
first-write acceptance, a Power BI workspace or a Fabric deployment.

The actual source/destination selections, account, tenant, connector and native
acceptance records remain with the existing deployment owner. Reconcile the
current private receipt before an authorized operation; do not replay the old
audit's operations or change its retained historical conclusions.
